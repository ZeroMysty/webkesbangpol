# Maintenance & Utility Scripts

Direktori ini berisi skrip-skrip utilitas dan pemeliharaan yang digunakan dalam pengembangan:

- **`extract_artikel.cjs`**: Skrip migrasi untuk mengekstrak inline CSS dari blade views artikel ke `public/assets/css/landingpage-artikel.css`.
- **`extract_dashboard.cjs`**: Skrip migrasi untuk mengekstrak inline CSS dari blade views dashboard.
- **`extract_informasi.cjs`**: Skrip migrasi untuk mengekstrak inline CSS dari blade views informasi.
- **`extract_mitra.cjs`**: Skrip migrasi untuk mengekstrak inline CSS dari blade views mitra.
- **`replace_css.cjs`**: Skrip utilitas untuk melakukan bulk replace referensi CSS.
- **`seed_struktur.php`**: Skrip awal struktur organisasi (sekarang sudah diintegrasikan ke `database/seeders/StrukturorSeeder.php`).
